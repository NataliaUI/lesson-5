# My links - Project Brief
A dashboard where to see the current standings of the World Cup 2026, clean design, mobile first.

## Tech
– Pure HTML, CSS, and JavaScript – no frameworks, no build tool
– Single index.html file (CSS and JS can be separate files)
– Deploys to Vercel as a static site

## Design
– Centered layout, max width 1080px
– World Cup 2026 as the heading, short description underneath
– Dark mode by default with a light/dark toggle
– Smooth hover animations on the link buttons
– Google font: Roboto

## Links
Display these as a sticky, eyebrow navigation:
– Overview
– Matches
– Standings
– Bracket

## Nice to have
– Subtle gradients or animated background
– Suble parallax effect
– Link buttons have icons (use simple SVG) 
– Footer with "Made with blood, sweat, and tears"
