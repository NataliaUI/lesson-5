# World Cup 2026 Dashboard

A mobile-first tournament dashboard for the World Cup 2026 experience, built with plain HTML, CSS, and JavaScript.

## Overview

This project matches the current live site with a sticky eyebrow navigation, a polished hero section, a matches table, a standings table, a knockout bracket, and a poll modal. The layout is designed to feel like a modern sports dashboard with a dark-first aesthetic and a light/dark toggle.

## What’s Included

- Sticky header with the World Cup 2026 brand badge and section links for Overview, Matches, Standings, and Bracket
- Hero area with live dashboard messaging and quick action cards for each section
- Upcoming matches section with stage, venue, and kickoff details
- Standings section showing team, group, points, and goal difference
- Bracket section with quarterfinal and final previews
- Light/dark theme toggle that is saved in local storage
- Poll modal that asks visitors which team they think will win
- Responsive layout tuned for both mobile and desktop screens

## Project Files

- index.html — page structure and all main sections
- styles.css — visual styling, theme colors, layout, and responsive behavior
- script.js — theme switching, poll modal behavior, and scroll animation
- readme.md — project summary and usage notes

## How to Use

1. Open index.html in a browser.
2. Use the top navigation to jump between Overview, Matches, Standings, and Bracket.
3. Click the theme button to switch between light and dark mode.
4. Submit the poll once to dismiss the modal.

## Notes

This is a static front-end project with no backend. Theme preference and poll visibility are both stored locally in the browser.
